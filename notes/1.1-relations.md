# relations

Modal logic interprets $\Box$ and $\Diamond$ over a set of worlds equipped with
a binary relation. Almost every result later in the course turns on which
*properties* that relation has, so we begin with them.

## ordered pairs and relations

Ordered Pair

:	$\langle x, y \rangle$ is the ordered pair of $x$ and $y$. Order matters:
	$\langle x, y \rangle = \langle u, v \rangle$ if and only if $x = u$ and $y = v$.

Binary Relation

:	A *binary relation* $R$ on a set $W$ is a set of ordered pairs of members of
	$W$, that is, $R \subseteq W \times W$.

We write $Rxy$ as an abbreviation for $\langle x, y \rangle \in R$, and read it
as '$x$ sees $y$' or '$y$ is accessible from $x$'.

## properties of relations

Each property below will later correspond to a modal axiom. Let $R$ be a binary
relation on $W$.

Reflexivity

:	$R$ is *reflexive* if and only if $Rxx$ for every $x \in W$.

Symmetry

:	$R$ is *symmetric* if and only if for all $x, y \in W$, if $Rxy$ then $Ryx$.

Transitivity

:	$R$ is *transitive* if and only if for all $x, y, z \in W$, if $Rxy$ and
	$Ryz$, then $Rxz$.

Seriality

:	$R$ is *serial* if and only if for every $x \in W$ there is some $y \in W$
	such that $Rxy$.

Euclidean

:	$R$ is *euclidean* if and only if for all $x, y, z \in W$, if $Rxy$ and
	$Rxz$, then $Ryz$.

## a warning about independence

These properties are independent of one another in ways that are easy to
misjudge. Two cautionary cases:

- A relation may be symmetric and transitive without being reflexive. Let
  $W = \{1, 2\}$ and $R = \{\langle 1, 1 \rangle\}$. Then $R$ is symmetric and
  transitive, but $2$ does not see itself.

- A relation may be euclidean without being symmetric. Seriality does not follow
  from reflexivity's failure either.

## why this matters later

We will prove that a frame validates a given axiom exactly when its relation has
the corresponding property:

| Axiom | Schema | Property of $R$ |
|-------|--------|-----------------|
| D | $\Box \varphi \to \Diamond \varphi$ | serial |
| T | $\Box \varphi \to \varphi$ | reflexive |
| B | $\varphi \to \Box \Diamond \varphi$ | symmetric |
| 4 | $\Box \varphi \to \Box \Box \varphi$ | transitive |
| 5 | $\Diamond \varphi \to \Box \Diamond \varphi$ | euclidean |

Keep this table close. It is the spine of the completeness results in the second
half of the course.
